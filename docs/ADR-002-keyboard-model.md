# ADR-002: 两层键位模型 — 字母选程序，数字选窗口

- 状态: 已接受 (2026-08-02)
- 关联: [[glossary]]

## 背景

原始需求是「分类 → 程序 → 切换」，且要求按代号切换。早期方案演化出三层（分类键→程序键→窗口编号），按键链太长。用户重构模型为「每个程序就是一个分类」，最终砍掉分组层。

## 决策

两层直达模型：

- **第一层（程序层）**：覆盖层列出所有程序条目，每个条目绑定一个字母键（配置手动指定，冲突时启动校验报错）。取消分类分组，程序平铺。
- **第二层（窗口层）**：按字母进入该程序的窗口列表，每个窗口有数字编号（Z 序，见 ADR-003）。编号支持多位数字串（如按 `12` = 第 12 个窗口），无上限。
- **单窗口直切**：目标程序只有 1 个窗口时，按字母直接切换，不显示第二层。
- **轮询切换**：第二层内再按同字母，切到该程序下一个窗口（编号递增循环）。
- **Esc 逐层回退**：第二层 Esc 回程序层，程序层 Esc 关闭覆盖层。

## 后果

- 最常用路径只有两次按键（字母+数字），单窗口路径一次按键
- 取消分类后，程序多时第一层列表变长（每字母一个程序，26 字母上限 + 可冲突配置校验）
- 未运行程序在两层中都显示为灰色不可选（只切已运行，ADR-003）
