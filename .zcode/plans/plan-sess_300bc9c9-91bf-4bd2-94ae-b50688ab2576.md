## WinHop 覆盖层顺畅化 + 视觉升级方案

目标：消除唤出/关闭的突兀感，整体更好看。背景效果与关闭动画均做成**设置开关**，方便你对比两种实现。

### 一、背景效果（3 档，新增设置项 `overlay_bg`）
- **solid（现状）**：纯不透明 `var(--bg)`，保留作回退。
- **translucent（新默认）**：`#app` 背景改 `rgba(var(--bg-rgb), 0.78)`，桌面隐约可见，纯 CSS 零风险。
- **acrylic（毛玻璃）**：Rust 调 Tauri 2 `win.set_effects(Effect::Acrylic)`（系统级模糊，Win10 19045 用 accent policy），CSS 上叠加更淡的色调 `rgba(bg, ~0.45)` 让模糊透出来。
  - 已知坑：Win10 下全屏/最大化窗口可能不渲染 Acrylic。实现时先试 `set_fullscreen(true)` 直接生效；若不渲染，改为「窗口铺满显示器尺寸」替代 OS 全屏（open/close 中全屏逻辑分支处理）。
  - 切换命令 `set_overlay_bg(mode)`：Rust 应用/清除 effects + 前端 `#app[data-bg=...]` 切 CSS，设置页与主题一样**实时预览、取消还原**。
  - 注册表：`config.rs` 加 `OVERLAY_BGS` 白名单常量校验（模式同 `THEMES`），显示名归 i18n。

### 二、关闭淡出动画（设置项 `close_anim`，默认开）
仅作用于**退出类关闭**（Esc 空筛选 / 点击外部 / 再按热键 / 托盘点击）；**切换类关闭（Space/数字/回车/跳转）保持现有瞬时路径不动**，不牺牲瞬切手感。

实现（遵守 design.md:114 的激活时序红线，且以构造顺序保证）：
1. `close_impl` 增加 `animate` 分支：置 `visible=false`、清 overlay hwnd/缩略图后，**不 `win.hide()`**，把激活目标存入新原子 `hide_target`、记录 `hide_pending_since`，emit 的 `Render` 增加 `anim_close: true` 字段。
2. 前端收到 `anim_close` → `#app` 加 `.closing` 类（opacity 过渡 ~110ms）→ 完成后 `invoke("overlay_hidden")`；期间收到 `visible=true`（快速重呼）则取消淡出、不发回执。
3. 新命令 `overlay_hidden`：校验 `visible==false`（防迟到回执杀掉刚重开的覆盖层）→ `win.hide()` → 取 `hide_target` spawn 激活线程——激活仍在 emit 与 hide 之后，红线顺序不变。
4. 竞态防护：淡出期间 `Focused(false)` 清空 `hide_target`；看门狗扩展「`visible=false` 但窗口仍可见超 1.5s」→ 强制 hide + 激活（webview 挂死兜底）。
5. `prefers-reduced-motion` 下跳过计时直接回执。

### 三、程序行应用图标
- `windows.rs` 新增 `extract_icon`：`SHGetFileInfoW`（32px）→ `GetIconInfo`+`GetDIBits` 取 BGRA → 转 RGBA 并还原预乘 alpha → base64（新增轻量 `base64` crate，不做 PNG 编码）。
- 内存放 `Inner` 的 `Mutex<HashMap<process, dataUrl>>` 缓存；`open()` 时对列表中进程提取一次，独立 `icons` 事件发前端（**不放进每次按键都发的 `overlay` 事件**）。PWA（`pwa#`）用宿主浏览器图标，取不到则留固定空槽不跳版。
- 前端行内插 `<img class="picon">`，尺寸 `calc(20px * var(--ui-scale))`。

### 四、视觉打磨（纯 CSS + 少量 JS）
1. **整行高亮**：`.row.active` = 淡 accent 底 + inset 描边铺满整行，`.row:hover` 整行中性淡底；名称段专属背景移除；同步 ui-design.md 选中规则。
2. **阴影 token 化**：新增 `--shadow-panel`/`--shadow-float`，替换 styles.css 里 4 处硬编码 `rgba(0,0,0,…)`（现违反「颜色只用变量」规则）。
3. **唤出动效**：`#app` 的 `overlay-in` 保留（半透明背景下成平滑压暗）；程序行新增 `row-in` 逐行 10ms 级联（仅「从关闭→打开」的首帧渲染播放，键入筛选重建不重播，cap 60ms）；窗口层 `.wlist`/`.wpreview` 仅 opacity 淡入（**不用 transform**，避免 DWM 缩略图 `getBoundingClientRect` 与动画期错位；`thumb_set` 布局推迟到动画结束后）。
4. 全部新动效沿用 `--dur`/`--ease`，被现有 `prefers-reduced-motion` 全局归零覆盖（实现时核对选择器）。

### 五、设置页 & 文档 & 测试
- 设置页新增两个 `.setting-section`（背景效果 radio×3、关闭动画 radio×2），原生 radio + accent，i18n 双语。
- 同一提交内同步文档：`design.md`（新配置项、关闭新时序/看门狗、图标管线）、`ui-design.md`（新 token、行高亮新规、动效清单）、`TODO.md`（记录 Acrylic 在 Win10 实测结论）。
- 测试：`cargo test` 增配置校验/`Render` 序列化用例；`node --test` + `node --check`；`cargo build` 后启动 `winhop.exe` 查 `winhop.log`，按 build.md 清单手测（你逐个对比 3 种背景 × 2 种关闭动画）。
