# WinHop v0.3.4

## 中文

**新增「删除程序配置」，不再需要的软件不再灰色占位**

- ✨ ✎ 编辑面板新增「删除」按钮：移除不再需要的软件名称和代号，未运行的程序立即从列表消失（不再灰色显示），列表更干净
- ✨ 删除后若该程序正在运行，仍会以未配置（`·`）出现，随时可重新配代号
- 📌 「删除」与「屏蔽」分清：删除只清掉你保存的名称/代号（程序运行时仍列出）；屏蔽是加入黑名单、运行时也彻底隐藏（设置页可解除）

## English

**New: delete a program's config — apps you no longer need stop cluttering the list in grey**

- ✨ The ✎ edit panel has a new "Delete" button: remove a saved name/code you no longer need. A program that isn't running disappears from the list immediately (no more greyed-out entries)
- ✨ If the program is currently running, it still shows up unconfigured (`·`) and can be re-configured anytime
- 📌 "Delete" vs "Block": Delete only clears the saved name/code (the app still appears while running); Block adds it to a blacklist and hides it entirely even while running (unblock in settings)
